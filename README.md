# 数学研习室

基于《数学二真题全卷满分手册》的 React + Vite 静态学习站点。

## 内容与学习

- 70 个方法单元：22 个极限与微积分、30 个综合应用、18 个线性代数。
- 71 道完整真题示例，直接读取 exam-archive 的原生 HTML/KaTeX，保留题干、选项与原笔记读题演示，文字可选择、公式随字号缩放。
- 每单元按识别入口、理解条件、推演流程、真题应用、解释复盘组织。
- 70 道新增理解练习，6 个交互数学实验。
- 整卷策略、易混辨析与逐年题位索引转换为站内参考页。
- 浏览器本地进度、收藏、错因、笔记与自评复习，支持 JSON 导入导出。
- 顶部提供浅色/深色切换、跟随系统和 100/120/140/160% 四档字号，另可滑动自定义 100–200%；偏好在当前浏览器保存。
- Zen 模式居中放大学习正文，收起辅助 UI，保留五阶段学习与笔记；Esc 逐层关闭浮层及退出专注。
- 页面与学习阶段采用轻微过渡，支持系统减少动态效果偏好；Ctrl/Cmd K 打开并聚焦搜索。
- 复盘文字选填，可直接自评；复习参考指数遗忘模型及间隔重复，综合两道选择题首次正确率和真题自报反馈。初次约12小时至3天，到期掌握稳定后延长，上限90天；未答不算错，同次重复自评不延长间隔。这是未经过个人长期数据校准的启发式建议。

## 运行

手写支持题目临时批注，以及按题答题、复盘和笔记的本机保存。输入区在文字与手写间切换并记住选择。默认仅响应笔，支持常见笔侧键/笔尾橡皮信号、撤销重做、增减空白空间与 SVG 导出；学习记录 JSON v2 包含 IndexedDB 笔迹并兼容旧记录导入。不同网址的存储互相独立，从局域网迁移到正式站请先导出再导入。

题目复制提供由归档公式结构转换的 LaTeX 分享文本；转换不等同于原始源码，分享前请对照原题。局域网 HTTP 可展开文字手动复制。

Node.js 22.12+ 或 24。

```bash
npm ci
npm run dev
npm run build
```

部署产物为 `dist`。采用 hash 路由，无需服务器重写。静态资源和 KaTeX 字体随站打包，无外部字体请求。HTTPS 下支持安装 PWA；首次联网完成缓存后，全70单元、71题、实验和公式字体可离线使用，原笔记PDF和来源附件需联网。学习记录仅在当前浏览器/安装环境保存，没有多设备同步。新版本在阅读设置提供更新按钮，确认后重新打开。

PWA 构建由 `scripts/pwa-build.mjs` 生成带内容指纹的 service worker，同版应用壳、字体及题目一并预缓存；未完成下载不会激活该版本。Chrome/Edge 可从阅读设置或浏览器菜单安装；iOS Safari 使用分享→添加到主屏幕。

## 验证

```bash
node scripts/audit.mjs
npx playwright test
```

测试使用本机 Edge 和 127.0.0.1:5173；可设置 SITE_URL 指向部署站点。核对公式解析、70 单元题干资源、学习流程与本地持久化，以及桌面/手机布局。

`src/data/coverage.json` 记录内容覆盖与源文件 SHA256。`scripts/extract.py` 在原资料目录旁运行，可从原始 LaTeX 重建数据与公开资源，并调用 `scripts/archive_questions.py` 生成原生题目 JSON。后者需 Python beautifulsoup4；`src/data/archive-coverage.json` 记录71题原始HTML指纹及文本、431个公式、120个选项完整性。

## 来源边界

知识公式、识别信号、方法流程、变式、题干与读题演示来自原笔记。新增练习、实验、引导问题与自评复习为本站教学补充。题干为本地网页档案排版，并非官方扫描。研究疑点可在站点材料页查阅。原笔记难度、用时与本站复习间隔均为训练建议；完成状态不等同于能力认证。

方法论参考 [learn-from-materials](https://github.com/dmoshehun-prog/learn-from-materials) 的来源追溯、事实与新增内容分离、自测与本地优先原则。本站独立实现，未复制其程序。
