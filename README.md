# 数学研习室

基于《数学二真题全卷满分手册》的 React + Vite 静态学习站点。

## 内容与学习

- 70 个方法单元：22 个极限与微积分、30 个综合应用、18 个线性代数。
- 71 道完整真题示例，保留题干、选项与原笔记读题演示。
- 每单元按识别入口、理解条件、推演流程、真题应用、解释复盘组织。
- 70 道新增理解练习，6 个交互数学实验。
- 整卷策略、易混辨析与逐年题位索引转换为站内参考页。
- 浏览器本地进度、收藏、错因、笔记与自评复习，支持 JSON 导入导出。

## 运行

Node.js 22.12+ 或 24。

```bash
npm ci
npm run dev
npm run build
```

部署产物为 `dist`。采用 hash 路由，无需服务器重写。静态资源和 KaTeX 字体随站打包，无外部字体请求。首次加载需要网络；没有声明支持离线缓存或多设备同步。

## 验证

```bash
node scripts/audit.mjs
npx playwright test
```

测试使用本机 Edge 和 127.0.0.1:5173；可设置 SITE_URL 指向部署站点。核对公式解析、70 单元题干资源、学习流程与本地持久化，以及桌面/手机布局。

`src/data/coverage.json` 记录内容覆盖与源文件 SHA256。`scripts/extract.py` 在原资料目录旁运行，可从原始 LaTeX 重建数据与公开资源。

## 来源边界

知识公式、识别信号、方法流程、变式、题干与读题演示来自原笔记。新增练习、实验、引导问题与自评复习为本站教学补充。题干为本地网页档案排版，并非官方扫描。研究疑点可在站点材料页查阅。原笔记难度、用时与本站复习间隔均为训练建议；完成状态不等同于能力认证。

方法论参考 [learn-from-materials](https://github.com/dmoshehun-prog/learn-from-materials) 的来源追溯、事实与新增内容分离、自测与本地优先原则。本站独立实现，未复制其程序。
